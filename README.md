# Калькулятор баллов за СОЧ

Калькулятор показывает, сколько баллов нужно набрать за предстоящий СОЧ, чтобы получить **4** или **5** за четверть.

## Как запустить

Открой `index.html` двойным кликом. Страница работает в браузере без установки и интернета. Файл `Расчет.js` должен лежать в той же папке, что и `index.html`.

## Как пользоваться

1. Выбери желаемую оценку в списке.
2. Введи вклад ФО и СОР в итог четверти. Каждый вклад должен быть от **0 до 25**. Можно вводить дробные числа с запятой или точкой, например `22,5`.
3. Введи максимальный балл за СОЧ. Это целое число больше нуля.
4. Нажми **«Отправить»**. Калькулятор покажет минимальный балл для выбранной оценки или сообщит, что даже максимума за СОЧ не хватит.

## Как считается результат

ФО и СОР вместе дают до 50 процентных пунктов, СОЧ даёт ещё до 50. Для четвёрки нужно набрать минимум **65%** за четверть, для пятёрки — **85%**.

```text
Баллы за СОЧ = (порог оценки − ФО − СОР) × максимум за СОЧ / 50
```

Результат округляется вверх до целого балла. Например, при ФО **20**, СОР **22** и максимуме СОЧ **30** для пятёрки нужно `(85 − 20 − 22) × 30 / 50 = 25,8`, то есть **26 из 30 баллов**.
