# Калькулятор СОЧ и СОР

Два отдельных окна: сколько баллов нужно за СОЧ для оценки за четверть и какая оценка получилась за уже написанный СОР. Приложение работает без интернета.

## Оценка за СОР

Нажми **«Оценка за СОР ↗»** в главном окне. Откроется отдельное окно с полями **«Набранный балл»** и **«Максимальный балл за СОР»**. Введи значения и нажми **«Рассчитать оценку»** или Enter.

```text
Процент = набранный балл / максимальный балл × 100
```

Шкала: от **85% — 5**, от **65% — 4**, от **40% — 3**, ниже **40% — 2**. Например, **8 из 10 = 80%, оценка 4**, а **8 из 20 = 40%, оценка 3**. Процент не округляется до целого перед определением оценки.

Поддерживаются дробные баллы с запятой или точкой: `8,5` и `8.5`. Максимум должен быть больше нуля, набранный балл — от нуля до максимума. Результат СОР не меняет введённый вклад СОР в расчёте четверти: это разные показатели.

## Нужный балл за СОЧ

1. Выбери желаемую оценку — **4** или **5**.
2. Введи вклад ФО и СОР в итог четверти — каждый от **0 до 25**. Поддерживаются запятая и точка.
3. Введи максимальный балл за СОЧ — целое число больше нуля.
4. Нажми **«Отправить»** или Enter. Появится минимальный балл либо сообщение, что даже максимума не хватит.

ФО и СОР вместе дают до 50 процентных пунктов, СОЧ — ещё до 50. Порог четвёрки — **65%**, пятёрки — **85%**.

```text
Баллы за СОЧ = (порог оценки − ФО − СОР) × максимум за СОЧ / 50
```

Результат округляется вверх до целого. При ФО **20**, СОР **22** и максимуме СОЧ **30** для пятёрки нужно `(85 − 20 − 22) × 30 / 50 = 25,8`, то есть **26 из 30 баллов**.

## Настольное приложение (.exe / .dmg)

Нужен Node.js 24. Для запуска из исходников:

```sh
npm ci
npm start
```

Сборка установщика на Windows:

```sh
npm run dist:win
```

Сборка на macOS для Intel и Apple Silicon:

```sh
npm run dist:mac
```

Файлы появятся в `dist/`. Готовые сборки также создаёт GitHub Actions: **Actions → Build desktop calculator → успешный запуск → Artifacts**. `calculator-windows` содержит установщик `.exe`, `calculator-macos` — `.dmg` для x64 и arm64. Артефакты хранятся 30 дней. Сборки не подписаны и не нотарифицированы; Windows/macOS могут запросить подтверждение запуска.

## Браузерная версия

Открой `index.html` двойным кликом. Все HTML, JS и CSS файлы должны оставаться в одной папке. Кнопка СОР открывает отдельное окно браузера; браузер может отобразить его как вкладку в зависимости от своих настроек. Разреши всплывающие окна для калькулятора, если они заблокированы.

GitHub Pages публикуется из `main`; workflow копирует также файлы окна СОР.

## Проверки

```sh
npm test
npx playwright install chromium
npm run test:ui
npm run test:desktop
```

Для браузерных проверок нужен Python 3 (локальный HTTP-сервер). Можно использовать установленный Chromium, задав переменную `CHROMIUM_PATH`. Проверка Electron требует графического сеанса; она также запускается на Windows и macOS в workflow сборки.
